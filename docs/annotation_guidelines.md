## 1. Что мы размечаем и зачем

Наша цель — создать **эталонный датасет** для оценки и обучения моделей кластеризации тем (Topic Modeling) на Telegram-новостях на русском языке.

Каждое сообщение размечается вручную: разметчик присваивает ему крупную тему, конкретный сюжет, оценивает новизну и качество. В итоге получается датасет с «золотыми» метками, которые можно сравнивать с выходом алгоритмов кластеризации (HDBSCAN, LDA, BERTopic и др.).

---

## 2. Структура разметки

Каждое сообщение имеет **5 измерений**:

| Поле | Тип | Описание |
|------|-----|----------|
| `broad_topic` | строка | Крупная категория (Политика, Экономика…) |
| `storyline` | строка | Конкретный сюжет или событие |
| `is_new_storyline` | bool | Впервые или продолжение |
| `quality` | enum | `useful` / `noise` / `duplicate` |
| `annotator_confidence` | 0.0–1.0 | Уверенность разметчика |

---

## 3. Крупные темы

Используйте одну из стандартных категорий:

| Категория | Что входит |
|-----------|------------|
| **Политика** | Выборы, законы, деятельность государственных органов и партий, назначения чиновников |
| **Экономика** | Финансы, рынки, бизнес, цены, ставки ЦБ, торговля, санкции (экономическая сторона) |
| **Безопасность** | Военные конфликты, войны, теракты, криминал, оборона |
| **Международные отношения** | Дипломатия, переговоры, встречи лидеров, санкции (геополитическая сторона) |
| **Общество** | Социальные события, протесты, права человека, демография, миграция |
| **Технологии** | IT, искусственный интеллект, космос, наука, инновации |
| **Здоровье** | Медицина, эпидемии, фармацевтика, система здравоохранения |
| **Культура** | Искусство, кино, музыка, литература, спорт, образование, религия, СМИ |
| **Другое** | Не подходит ни под одну категорию выше |

**Правила выбора темы:**
- Выбирайте **доминирующую** тему, если сообщение затрагивает несколько.
- «Санкции» — экономическая или геополитическая тема в зависимости от акцента.
- Тема **«Другое»** — запасной вариант; стараемся использовать её не более 5–10% задач.

## 4. Тема vs. Сюжет/событие

**Тема** — категория верхнего уровня.  
**Сюжет** — конкретное событие или история, которая разворачивается во времени.

```
Тема:    Экономика
Сюжет:   «Центробанк повысил ключевую ставку до 21% — октябрь 2024»

Тема:    Безопасность
Сюжет:   «Обмен военнопленными между Россией и Украиной — декабрь 2024»

Тема:    Технологии
Сюжет:   «Запуск ChatGPT-5 и реакция рынка»
```

**Правила:**

- Один сюжет может продолжаться **неделями**. Несколько сообщений об одном событии → **один сюжет**.
- Формулируйте сюжет **конкретно**: не «война», а «война в Газе — наземная операция».
- Если конкретное событие вам неизвестно, опишите **предполагаемую суть**.
- Не нужно искать официальные названия — своими словами достаточно.

---

## 5. Новый сюжет vs. продолжение

**Новый сюжет** (`is_new_storyline = true`):
- Вы ещё не видели этот сюжет в уже размеченных сообщениях.
- Событие произошло впервые.

**Продолжение** (`is_new_storyline = false`):
- Сюжет уже упоминался ранее — это обновление или развитие.
- Вы разметили похожие сообщения с тем же сюжетом.

> **Если сомневаетесь** — выбирайте «Продолжение» (`false`). Пресловутые первые упоминания важнее ложных положительных.

## 6. Качество сообщения: полезное / шум / дубль

### ✅ Полезное (`useful`)

Сообщение несёт **новую или ценную информацию** и:
- Содержит ≥ 5 слов осмысленного текста.
- Не является точной копией другого сообщения.
- Не является рекламой или спамом.

Мнение или комментарий без фактов → `useful`, если текст содержательный.

### ⚠️ Шум (`noise`)

- Реклама, промо, спам.
- Только ссылка без пояснения.
- Сообщение с менее 5 словами осмысленного текста.
- Системные сообщения бота.
- Опрос без контекста.
- Только картинка / видео без текста.
- Технические объявления (канал переименован, бот обновлён).

### ⊘ Дубль (`duplicate`)

- **Почти дословное** повторение другого сообщения (из того же или другого канала).
- Репост без добавленной информации.
- Тот же факт, те же детали — только другой источник.

> Если в репосте есть **существенный комментарий** — это `useful`.

## 7. Неоднозначные случаи

| Ситуация | Рекомендация |
|----------|--------------|
| Сообщение пересекает несколько тем | Выбрать **доминирующую** |
| Только картинка без текста | `noise` |
| Эмоциональное сообщение без фактов | `useful`, тема по контексту |
| Репост с коротким комментарием | `useful` если комментарий добавляет смысл; `duplicate` если нет |
| Очень короткое сообщение (1–4 слова) | `noise` |
| Гибридная тема (Экономика + Политика) | Тема по акценту в тексте |
| Сообщение на иностранном языке | Размечайте по содержанию; `language` уже зафиксирован системой |

## 8. Сущности

Поле **сущности** заполняется автоматически NER-моделью. Разметчик **исправляет только явные ошибки**:

| Тип | Что относится |
|-----|---------------|
| `PER` | Персоны: Путин, Набиуллина, Байден |
| `ORG` | Организации: Сбербанк, ООН, ЦБ РФ |
| `LOC` | Места: Москва, Ближний Восток, Украина |
| `MISC` | Прочее: «Газпром Нефть», «закон Яровой», «Давосский форум» |

Если автоматическая разметка сущностей правильная — оставьте как есть. Исправлений не требуется при незначительных ошибках.

## 9. Уверенность разметчика

Ползунок от **0.0** до **1.0**:

| Значение | Когда использовать |
|----------|--------------------|
| **0.9–1.0** | Сообщение однозначно, тема и качество очевидны |
| **0.7–0.9** | Небольшие сомнения, но выбор достаточно уверен |
| **0.5–0.7** | Серьёзные сомнения; сообщение неоднозначно |
| **< 0.5** | Очень сложный случай; нужна проверка лид-разметчиком |

Задачи с `confidence < 0.6` автоматически попадают в очередь на пересмотр.

## 10. Inter-Annotator Agreement (IAA)

Часть задач назначается **нескольким разметчикам одновременно** (без ведома друг друга). Это необходимо для измерения согласованности.

**Метрика:** Cohen's κ по полям `broad_topic` и `quality`.

| κ | Интерпретация |
|---|---------------|
| < 0.40 | Плохая согласованность |
| 0.40–0.60 | Умеренная |
| 0.60–0.80 | Хорошая ✓ |
| > 0.80 | Отличная |

При κ < 0.6 проводится **калибровочная сессия**: разметчики совместно разбирают спорные случаи.

## 11. Рабочий процесс в UI

1. Откройте `/annotation/topics`.
2. В левой панели выберите вкладку **«Задачи»**, отфильтруйте по статусу `pending`.
3. Кликните на задачу → в правой панели откроется карточка сообщения.
4. Прочитайте текст, выберите **тему**, введите **сюжет**.
5. Переключите тумблер **«Новый сюжет»** если это первое появление.
6. Нажмите на нужное **качество** (Полезное / Шум / Дубль).
7. Установите **уверенность** (ползунок).
8. При необходимости добавьте **комментарий**.
9. Нажмите **«Сохранить»** → система автоматически перейдёт к следующей задаче.
10. Нажмите **«Пропустить»** если задача требует обсуждения.

**Горячий старт:** нажмите «Начать с первой задачи» на пустом рабочем поле.

## 12. Примеры разметки

### Пример 1 — Полезное, Экономика

```
Текст: «ЦБ России повысил ключевую ставку с 19% до 21% — рекордный уровень за 20 лет»

broad_topic:      Экономика
storyline:        Повышение ключевой ставки ЦБ до 21% (октябрь 2024)
is_new_storyline: true
quality:          useful
confidence:       0.95
```

### Пример 2 — Дубль

```
Текст: «ЦБ поднял ставку до 21%. Источник: РБК»

(идентично предыдущему сообщению, без новой информации)

broad_topic:      Экономика
storyline:        Повышение ключевой ставки ЦБ до 21%
is_new_storyline: false
quality:          duplicate
confidence:       0.90
```

### Пример 3 — Шум

```
Текст: «Подписывайтесь на наш канал! 🔥 Ссылка в bio»

broad_topic:      (пусто)
storyline:        (пусто)
quality:          noise
confidence:       1.0
```

### Пример 4 — Неоднозначный случай (мнение)

```
Текст: «Повышение ставки ЦБ — это катастрофа для малого бизнеса. Мы снова в ловушке.»

broad_topic:      Экономика
storyline:        Повышение ключевой ставки ЦБ до 21% — реакция бизнеса
is_new_storyline: false  (продолжение сюжета)
quality:          useful  (содержательное мнение)
confidence:       0.75
comment:          «Субъективное мнение, но содержательное»
```

### Пример 5 — Безопасность + международные отношения

```
Текст: «Переговоры по обмену военнопленными возобновились при посредничестве ОАЭ»

broad_topic:      Безопасность  (акцент — военный конфликт)
storyline:        Обмен военнопленными Россия-Украина при посредничестве ОАЭ
is_new_storyline: false
quality:          useful
confidence:       0.80
comment:          «Могло бы быть "Международные отношения", выбрал "Безопасность" из-за военного контекста»
```
