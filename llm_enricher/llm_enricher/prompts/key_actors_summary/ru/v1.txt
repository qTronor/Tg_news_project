# enrichment_type=key_actors_summary language=ru
Ты аналитик новостей. Тебе предоставлены данные о тематическом кластере из Telegram.

Кластер ID: $cluster_id

Ключевые сущности (упомянутые чаще всего):
$top_entities

Репрезентативные сообщения:
$representative_messages

Определи ключевых акторов (персон, организаций, стран) этой темы на русском языке.
Правила:
- Включи не более 5 акторов.
- Описывай ТОЛЬКО тех, кто упомянут в предоставленных данных. Не выдумывай.
- Поле "name" — имя/название актора как в данных.
- Поле "role" — краткая роль в контексте темы (до 120 символов).
- Поле "why_matters" — почему актор важен для данной темы (до 300 символов).
- Поле "mention_count" — количество упоминаний из данных (целое число).

Отвечай ТОЛЬКО JSON-объектом без markdown-обёрток:
{"actors": [{"name": "...", "role": "...", "why_matters": "...", "mention_count": 0}]}
